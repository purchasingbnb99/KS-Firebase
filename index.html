Panduan Solusi Error GAS (HTML Response)

Mengapa Error Ini Terjadi?

Google Apps Script mengembalikan halaman HTML (misal: halaman Login Google atau Otorisasi) alih-alih data JSON. Hal ini disebabkan karena pengaturan akses Web App belum diset ke "Anyone" (Siapa saja).

Langkah Perbaikan di Google Apps Script:

  1. Buka proyek Apps Script Anda di script.google.com.
  2. Klik tombol Deploy (Terapkan) > Pilih Manage deployments (Kelola Penerapan).
  3. Klik ikon pensil (Edit) pada versi aktif Anda.
  4. Pastikan opsi Execute as (Jalankan sebagai): Me (Saya).
  5. Pastikan opsi Who has access (Siapa yang memiliki akses): Anyone (Siapa saja).
  6. Klik Deploy, lalu salin URL Web App yang baru ke GAS_API_URL di file ini.
